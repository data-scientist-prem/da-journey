# DA Journey

Private Data Analyst preparation web app (PWA) for one owner. Sign-in is locked to the owner's Google account; progress is stored only in the owner's browser and in a file in the owner's own Google Drive (`drive.file` scope).

This repository contains only the app code and the learning content (roadmap, practice problems with expected outputs, quizzes, resource links). No personal progress, logs or credentials are stored here.

Practice datasets referenced: Satish Dhawale's public practice files (GitHub), codebasics resume project challenges. Python practice content adapted from the owner's earlier Python trial.
